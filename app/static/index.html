🛡️ Critical Anti-Leakage Rules

  • Exclusion of Target Probabilities: All 8 *_resistance_probability columns were strictly purged prior to training.
  • Patient Identifier Protection: patient_id is discarded and never used as a predictive feature.
  • Stratified Isolation: Preprocessing and models were trained strictly on training splits without test leakage.

⚠️ Known Limitations

  • Synthetic Cohort: The current dataset is synthetic. Performance on real clinical AST data will differ.
  • Imbalanced Classes: Low-prevalence agents (e.g. Fosfomycin at 10.2%) suffer lower precision despite class weighting.
  • Non-Causal Attribution: SHAP values indicate associative mathematical feature weights, not biological causality.

🚀 Future Real-World Clinical Roadmap

The modular architecture separates dataset loaders, preprocessing transformers, model registries, and explainers. When transitioning to real-world Electronic Health Record (EHR) data (e.g. MIMIC-IV or institutional AST registries), the synthetic data module can be replaced without changing backend APIs or frontend dashboards.
